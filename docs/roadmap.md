# Best Website Support – Roadmap

## Vision
Best Website Support is designed to become a foundational layer across all managed WordPress sites, improving client experience, operational efficiency, and long-term recurring revenue.

---

## Current Status
- Stable release (v1.0.7) deployed to live client sites
- Core architecture refactored and hardened
- Update pipeline validated via real-world usage

---

- Implemented request-level settings caching
- Improved sanitization for structured inputs
- Scoped support email behavior safely
- Hardened admin UI cleanup logic
- Strengthened GitHub updater and release process

## Next High-Impact Enhancements

### 1. Fleet Management Layer (Core Strategic Priority)

Transform the plugin into a true operational control layer across all managed sites.

#### Client-Facing Signals (Trust + Positioning)
- “Last updated by Best Website” indicator
- “Site actively maintained” messaging
- Visible proof of ongoing care and management

#### System Status Panel
- WordPress version
- PHP version
- Plugin/theme update status
- Security / maintenance indicators
- Lightweight health summary

#### Action-Oriented Controls
- One-click “Request Update”
- One-click “Request Change”
- Structured request flows tied to support system

#### Operational Benefits
- Reinforces Best Website as an ongoing partner, not just a developer
- Reduces ambiguity around maintenance responsibility
- Creates a consistent, scalable client experience across all sites

### 2. Support → Revenue Pipeline
- Request categorization (bug, feature, content, urgent)
- Smart messaging tied to support tiers
- Metadata capture (URL, page, user)

### 3. Light Telemetry (Opt-In)
- Plugin version tracking across sites
- Feature usage signals
- Support request volume

### 4. In-Admin Request & Conversion Layer

Introduce a structured request system directly within the WordPress admin.

#### UI Entry Points
- Dashboard widget (primary)
- Admin bar menu (global access)
- Optional floating request button

#### Request Types
- Request a change
- Request a new page
- Report an issue
- General support

#### Smart Request Handling
- Context-aware forms (auto-fill URL, user info)
- Structured request data
- Integration with Zendesk or support system

#### Business Impact
- Centralizes all client communication
- Reduces unstructured support requests
- Creates natural upsell opportunities for support plans
- Reinforces Best Website as ongoing partner

#### Optional Growth Layer
- SEO / performance insights widget
- “Start SEO campaign” CTA
- Lead generation within admin experience
